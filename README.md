# 公交赶车闹钟（AstrBot 插件）

到点主动推送你候车站最近几辆公交车的到站信息，帮你判断几点出门赶车。**全国 500+ 城市可用。**

- 自定义提醒时间 + 日期规则（每天 / 工作日 / 非工作日 / 指定星期几）
- 设定城市、候车站、公交线路、方向
- 支持法定节假日与**调休补班日**（在线自动更新，无需手填）
- 数据来自「掌上公交」实时接口（h5.mygolbs.com）

## 效果

```
🚌 [三明市] 1路（往 碧湖枢纽站） · 候车：附小
1. 闽G09633D · 还有 10 站 · 约 12分钟
2. 闽G05386D · 还有 17 站 · 约 24分钟
🕘 起点预计发车：20:06
⏱ 数据时间 19:58
```

## 安装

1. 把 `astrbot_plugin_sm_bus_alarm` 整个目录放到 AstrBot 的 `data/plugins/` 下
2. 重启或热重载 AstrBot，在 WebUI「插件」页确认已加载
3. 依赖只有 `httpx`，一般会自动装；没装上就手动 `pip install httpx`

要求 AstrBot `>= 4.0.0`。

## 使用

### 1. 先确定城市

```
/buscity 福州          切换到福州
/buscity list 泉州     搜索支持的城市
/buscity               查看本会话当前城市
```

城市是**按会话**记的：群里设成福州，另一个私聊可以设成三明，互不影响。
没设过的会话用插件配置里的 `default_city`（默认三明市）。

### 2. 查站序

```
/buslines 1路 三叉街
```

输出该线路上包含「三叉街」的站点及站序（`/buslines 1路` 可列出全部站点，最多显示 30 个）。

### 3. 添加提醒

```
/busadd 07:30 工作日 1路 1 三叉街 3
```

参数依次是：

| 参数 | 说明 |
| --- | --- |
| 时间 | `HH:MM`，也接受 `0730` |
| 重复规则 | 见下表 |
| 线路名 | 需与 `/buslines` 显示的完整名称一致，如 `1路` |
| 方向 | `1`（上行）或 `2`（下行） |
| 候车站 | 站序数字如 `5`，或站名关键词如 `三叉街` |
| 车辆数 | 可选，推送显示最近几辆车，默认取配置里的 `default_top_n` |

订阅会记下添加时的城市，之后你切换城市也不会影响已有的提醒。

重复规则写法：

| 写法 | 含义 |
| --- | --- |
| `每天` / `每日` | 每天都提醒 |
| `工作日` | 周一至周五，**自动排除法定节假日、自动包含调休补班日** |
| `非工作日` | 周末与法定节假日，**自动排除调休补班日** |
| `12345` | 指定星期几，`1`=周一 … `7`=周日，可任意组合，如 `135` 表示周一三五 |
| `周一至周五` | 等同 `12345` |

### 4. 其余指令

| 指令 | 说明 |
| --- | --- |
| `/buslist` | 查看本会话的所有订阅 |
| `/busdel <编号>` | 删除订阅 |
| `/buson <编号>` | 启用订阅 |
| `/busoff <编号>` | 暂停订阅 |
| `/busnow <编号>` | 立即查询一次（不会影响定时提醒） |
| `/busstop` | 发一条主动推送测试，验证平台是否支持 |
| `/buscalendar` | 查看节假日数据来源、更新时间与今天的判定 |
| `/bushelp` | 帮助 |

订阅按会话隔离：在哪个群/私聊里加的，就推送到哪里。

## 配置

在 AstrBot WebUI 的插件配置页里改：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `default_city` | `三明市` | 插件默认城市，各会话可用 `/buscity` 单独覆盖 |
| `default_top_n` | `3` | 默认推送最近几辆车 |
| `request_timeout` | `10` | 接口超时（秒） |
| `holiday_api` | `true` | 是否自动获取在线节假日数据。关掉后「工作日 / 非工作日」只按周末判断 |
| `holiday_cache_days` | `7` | 节假日缓存有效期（天），过期自动重新拉取 |
| `holidays` | 空 | 额外手填的放假日，如 `2026-01-01,2026-01-02`；与在线数据取并集 |
| `workdays` | 空 | 额外手填的补班日，如 `2026-02-14`；这些日期即使落在周末也算工作日 |

## 数据来源

**实时公交**：「掌上公交」H5 接口（`h5.mygolbs.com/ApiData.do`）。
接口按**城市名**区分城市，所以三明、福州、厦门、北京等都能查；
`CMD=101` 取全国城市列表（565 个），`CMD=204` 校验城市是否开通，
`CMD=119/103/104` 分别取线路、站点表与实时车辆。
「还有几站 / 约几分钟」是按相邻站间距与分站速度逐段累加估算的，仅供参考。

**节假日 / 调休补班**：

- 主源 [holiday-cn](https://github.com/NateScarlet/holiday-cn)（jsDelivr 分发的静态 JSON，依据国务院办公厅放假通知文件）
- 备源 [timor.tech](https://timor.tech/api/holiday)
- 主源失败会自动回退备源；结果缓存到 `data/plugin_data/astrbot_plugin_sm_bus_alarm/holidays.json`
- 次年的调休安排通常每年 11~12 月才公布，届时会随缓存过期自动拉到

## 工作原理

插件内嵌一个 30 秒轮询的 asyncio 任务，每次 tick：

1. 刷新过期的节假日缓存
2. 取出到点且今天应当触发的订阅（用 `last_fire_date` 防止当天重复触发）
3. 按订阅记下的城市查询实时到站，通过 `context.send_message()` 主动推送到订阅所在会话

订阅与缓存在 `data/plugin_data/astrbot_plugin_sm_bus_alarm/` 下：

```
subscriptions.json   订阅数据（每条含 city）
session_cities.json  各会话当前城市
holidays.json        节假日缓存
```

## 注意事项

- 主动推送依赖平台能力。QQ（aiocqhttp）等平台支持；若 `/busstop` 收不到消息，说明当前平台不支持主动消息或需要额外配置
- 部分城市在线路查询上没问题，但**尚未开通实时到站数据**，此时 `/busnow` 会提示「这条线路还没开通实时到站数据」
- 依赖第三方公开接口，若上游改版可能失效；接口层集中在 `bus_api.py`，便于修复
- 请勿把轮询间隔、订阅数量调得过大，以免给上游接口造成压力

## 文件结构

```
astrbot_plugin_sm_bus_alarm/
├── metadata.yaml      插件元数据
├── requirements.txt   依赖（httpx）
├── _conf_schema.json  配置项定义
├── main.py            插件入口与指令
├── bus_api.py         实时公交接口封装与到站估算
├── holiday_api.py     在线节假日 / 补班日
├── alarm_store.py     订阅与城市持久化、日期规则
└── scheduler.py       定时调度与主动推送
```
