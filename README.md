# 公交赶车闹钟（AstrBot 插件）

到点主动推送你候车站最近几辆公交车的到站信息，帮你判断几点出门赶车。**全国 500+ 城市可用。**

- 自定义提醒时间 + 日期规则（每天 / 工作日 / 非工作日 / 指定星期几）
- 设定城市、候车站、公交线路、方向
- 支持法定节假日与**调休补班日**（在线自动更新，无需手填）
- 支持**自然语言直接查**：直接说「我在市政府，1路到哪了」，不必记指令、不必先订阅
- 会**自学你的出行习惯**，并记住家 / 公司 / 常去地点；没说方向时按时间和习惯自动判断
- 推送时附一张**线路地图**，标出线路走向、候车站与实时车辆位置
- 自带 AstrBot **Dashboard 插件页面**，可图形化管理订阅
- 数据来自「掌上公交」实时接口（h5.mygolbs.com）

## 效果

```
🚌 [三明市] 1路（往 碧湖枢纽站） · 候车：附小
1. 闽G09633D · 还有 10 站 · 约 12分钟
2. 闽G05386D · 还有 17 站 · 约 24分钟
🕘 起点预计发车：20:06
⏱ 数据时间 19:58
```

文字下方还会附一张这样的图：底图是线路走向，紫色是候车站，蓝色（带序号）是候选车辆，
灰色是其他在途车辆；线路本身按站间实时路况着色（绿=畅通 / 橙=缓行 / 红=拥堵），
左下角有图例。

## 安装

1. 把 `astrbot_plugin_bus_alarm` 整个目录放到 AstrBot 的 `data/plugins/` 下
2. 重启或热重载 AstrBot，在 WebUI「插件」页确认已加载
3. 依赖 `httpx` 与 `pillow`，一般会自动装；没装上就手动 `pip install httpx pillow`

要求 AstrBot `>= 4.0.0`。

## 使用

### 1. 先确定城市

```
/buscity 福州          切换到福州
/buscity list 泉州     搜索支持的城市
/buscity               查看本会话当前城市
```

城市是**按会话**记的：群里设成福州，另一个私聊可以设成三明，互不影响。
没设过的会话用插件配置里的 `default_city`（默认三明市）。

### 2. 查站序

```
/buslines 1路 三叉街
```

输出该线路上包含「三叉街」的站点及站序（`/buslines 1路` 可列出全部站点，最多显示 30 个）。

### 3. 添加提醒

```
/busadd 07:30 工作日 1路 1 三叉街 3
```

参数依次是：

| 参数 | 说明 |
| --- | --- |
| 时间 | `HH:MM`，也接受 `0730` |
| 重复规则 | 见下表 |
| 线路名 | 需与 `/buslines` 显示的完整名称一致，如 `1路` |
| 方向 | `1`（上行）或 `2`（下行） |
| 候车站 | 站序数字如 `5`，或站名关键词如 `三叉街` |
| 车辆数 | 可选，推送显示最近几辆车，默认取配置里的 `default_top_n` |

订阅会记下添加时的城市，之后你切换城市也不会影响已有的提醒。

重复规则写法：

| 写法 | 含义 |
| --- | --- |
| `每天` / `每日` | 每天都提醒 |
| `工作日` | 周一至周五，**自动排除法定节假日、自动包含调休补班日** |
| `非工作日` | 周末与法定节假日，**自动排除调休补班日** |
| `12345` | 指定星期几，`1`=周一 … `7`=周日，可任意组合，如 `135` 表示周一三五 |
| `周一至周五` | 等同 `12345` |

### 4. 直接问（自然语言）

不用记指令，也不用先建订阅，直接把需求说给 AI 听即可：

```
我在市政府，1路到哪了
帮我查一下 1 路还有几站到三叉街
早上上班那班车到哪了
```

AI 会从你的话里提取线路、站点，然后调用本插件的查询工具。**方向没说也不用管**，
插件按下面的顺序自己判断；实在判断不出来就上下行都查，把有车的那侧结果给你。

判断顺序：

1. **你明说了**——说了「去程 / 回程 / 上行 / 下行」，或者直接报终点站名
2. **地点语义 + 通勤时段**——候车站是你记过的「家」，且此刻在工作日早高峰 → 往「公司」的方向；反之为反方向
3. **时段习惯**——按你以往在相近时间点、坐同一线路时习惯的方向推断
4. **兜底**——上下行都查

推断出的方向会在结果下附一句「🤔」说明依据，供你核对。

> 这套判断依赖**出行习惯**：插件会在你每次查询 / 推送时静默记录「线路 + 方向 + 候车站 + 时间」，
> 记录只存在本地数据目录，不上传。数据攒够之前，判断不出来会自动退化成「两个方向都查」，
> 也不影响使用。查询本身**零配置、零订阅**即可用。

### 5. 出行习惯与地点记忆

| 指令 | 说明 |
| --- | --- |
| `/bushabit` | 看看插件学到了什么（地点记忆 + 近期出行习惯），以及记录条数 |
| `/bushabit clear` | 清空出行记录（地点记忆保留） |
| `/busplace` | 查看记住的家 / 公司 / 常去地点 |
| `/busplace home 市政府` | 手动设置「家」的站点 |
| `/busplace work 附小` | 手动设置「公司」的站点 |
| `/busplace frequent 超市站` | 记一个「常去」地点（最多 8 个） |
| `/busplace clear home` | 清除某一类地点记忆，`/busplace clear` 清除全部 |

除了手动设置，插件也会**自动认家认公司**：如果工作日早高峰你总在某个站上车、
晚高峰总在另一个站上车且方向相反，就会把前者的站记成「家」、后者记成「公司」，
并在 `/bushabit` 里标注是自动学到的。手动设置的地点优先级更高，不会被自动学习覆盖。

### 6. 其余指令

| 指令 | 说明 |
| --- | --- |
| `/buslist` | 查看本会话的所有订阅 |
| `/busdel <编号>` | 删除订阅 |
| `/buson <编号>` | 启用订阅 |
| `/busoff <编号>` | 暂停订阅 |
| `/busnow <编号>` | 立即查询一次（不会影响定时提醒） |
| `/busstop` | 发一条主动推送测试，验证平台是否支持 |
| `/buscalendar` | 查看节假日数据来源、更新时间与今天的判定 |
| `/bushelp` | 帮助 |

订阅按会话隔离：在哪个群/私聊里加的，就推送到哪里。

## WebUI 插件页面

在 AstrBot WebUI 的「插件」页找到本插件卡片，点进去就是这个页面（源码在 `pages/bus-alarm/`）。
页面与指令共用同一份订阅数据，改动立即生效，不用重启插件。

打不开或显示「加载失败」时依次排查：插件卡片是否处于「已启用」→ 点一次「重载」
（新增 / 删除页面目录后必须重载一次，否则 AstrBot 扫不到）→ 确认插件目录里存在
`pages/bus-alarm/index.html` → 确认已按 `requirements.txt` 安装好依赖
（缺 `pillow` 只会让「线路地图」标签页不可用，其他标签页照常）。

| 标签页 | 能做什么 |
| --- | --- |
| 订阅 | 查看全部订阅（含暂停状态、今天是否生效），一键启用 / 暂停 / 删除 / 立即查询并推送 |
| 新建 / 编辑 | 搜城市、搜线路、拉站点表，填时间和重复规则后保存 |
| 实时到站 | 选一条订阅，查候车站最近几辆车 |
| 线路地图 | 选一条订阅，看线路走向 + 当前车辆位置 |
| 节假日 | 查看数据来源、今天的判定、接下来的放假 / 补班日，可手动重新拉取 |

推送用的目标会话（`umo`）可以从「订阅」页已有的会话里下拉选择，不用手打。

## 线路地图

配置项 `map_in_push` 打开时，这些地方的消息都会在文字后附带一张地图：

- 到点自动推送（`scheduler.py`）
- `/busnow <编号>` 手动查询
- WebUI 里的「立即查询并推送」和「线路地图」页

地图上用颜色区分车辆状态与路况，左下角有对应图例：

| 颜色 | 含义 |
| --- | --- |
| 紫色水滴 | 你的候车站 |
| 蓝色公交车图标（右上带序号） | 候选车辆，序号与文字里的第 1、2… 辆一一对应 |
| 灰色公交车图标 | 其他在途车辆（已经过候车站的略深一些） |
| 绿 / 橙 / 红 线条 | 站间实时路况：畅通 / 缓行 / 拥堵 |
| 蓝色线条 | 没有路况数据时的线路走向 |

公交车图标按车辆实际行驶方向旋转（车头指向行驶方向）。
路况来自上游返回的**分站速度**，按「站点 i → 站点 i+1」分段着色，
只有部分城市提供了该数据，取不到时线路退化为单色蓝。

底图用的是高德公开瓦片（`webrd0x.is.autonavi.com`，无需 key），所以**运行环境需要能访问外网**；
取不到瓦片时会自动降级成「只有线路和站点、没有底图」的版本，不会影响推送。
线路本身没有经纬度数据时（少数城市），则跳过地图、只发文字。

## 配置

在 AstrBot WebUI 的插件配置页里改：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `default_city` | `三明市` | 插件默认城市，各会话可用 `/buscity` 单独覆盖 |
| `default_top_n` | `3` | 默认推送最近几辆车 |
| `request_timeout` | `10` | 接口超时（秒） |
| `map_in_push` | `true` | 推送时是否附带线路地图（含实时车辆位置） |
| `nl_query` | `true` | 是否允许自然语言直接查询（关掉后「直接问」只回一句提示，指令 / 订阅照常） |
| `habit_enabled` | `true` | 是否记录出行习惯并用于方向推断 |
| `place_auto_learn` | `true` | 是否自动认家 / 认公司（手动设置的地点始终生效） |
| `habit_retention_days` | `30` | 出行记录保留天数，超期自动清理 |
| `habit_min_samples` | `2` | 判定「习惯」所需的最少样本数，调大更保守 |
| `commute_am` | `07:00-09:00` | 早高峰时段，用于「家 → 公司」方向判断 |
| `commute_pm` | `17:00-19:00` | 晚高峰时段，用于「公司 → 家」方向判断 |
| `holiday_api` | `true` | 是否自动获取在线节假日数据。关掉后「工作日 / 非工作日」只按周末判断 |
| `holiday_cache_days` | `7` | 节假日缓存有效期（天），过期自动重新拉取 |
| `holidays` | 空 | 额外手填的放假日，如 `2026-01-01,2026-01-02`；与在线数据取并集 |
| `workdays` | 空 | 额外手填的补班日，如 `2026-02-14`；这些日期即使落在周末也算工作日 |

## 数据来源

**实时公交**：「掌上公交」H5 接口（`h5.mygolbs.com/ApiData.do`）。
接口按**城市名**区分城市，所以三明、福州、厦门、北京等都能查；
`CMD=101` 取全国城市列表（565 个），`CMD=204` 校验城市是否开通，
`CMD=119/103/104` 分别取线路、站点表与实时车辆；`CMD=104` 还会返回**站间路况**
（每段的分站速度与畅通状态），地图上的绿 / 橙 / 红就取自这里。
「还有几站 / 约几分钟」是按相邻站间距与分站速度逐段累加估算的，仅供参考。

**节假日 / 调休补班**：

- 主源 [holiday-cn](https://github.com/NateScarlet/holiday-cn)（jsDelivr 分发的静态 JSON，依据国务院办公厅放假通知文件）
- 备源 [timor.tech](https://timor.tech/api/holiday)
- 主源失败会自动回退备源；结果缓存到 `data/plugin_data/astrbot_plugin_bus_alarm/holidays.json`
- 次年的调休安排通常每年 11~12 月才公布，届时会随缓存过期自动拉到

**地图底图**：高德公开瓦片 `https://webrd0{1-4}.is.autonavi.com/appmaptile?...`（中文注记，无需 key），
只用于拼接推送里的静态图片，不涉及地理编码等其他服务。

## 工作原理

插件内嵌一个 30 秒轮询的 asyncio 任务，每次 tick：

1. 刷新过期的节假日缓存
2. 取出到点且今天应当触发的订阅（用 `last_fire_date` 防止当天重复触发）
3. 按订阅记下的城市查询实时到站，通过 `context.send_message()` 主动推送到订阅所在会话

订阅与缓存在 `data/plugin_data/astrbot_plugin_bus_alarm/` 下：

```
subscriptions.json   订阅数据（每条含 city）
session_cities.json  各会话当前城市
holidays.json        节假日缓存
profile.json         出行习惯与地点记忆（按会话隔离）
```

## 注意事项

- 主动推送依赖平台能力。QQ（aiocqhttp）等平台支持；若 `/busstop` 收不到消息，说明当前平台不支持主动消息或需要额外配置
- 部分城市在线路查询上没问题，但**尚未开通实时到站数据**，此时 `/busnow` 会提示「这条线路还没开通实时到站数据」
- 依赖第三方公开接口，若上游改版可能失效；接口层集中在 `bus_api.py`，便于修复
- 请勿把轮询间隔、订阅数量调得过大，以免给上游接口造成压力

## 文件结构

```
astrbot_plugin_bus_alarm/
├── metadata.yaml      插件元数据
├── CHANGELOG.md       版本变更记录
├── requirements.txt   依赖（httpx、pillow）
├── _conf_schema.json  配置项定义

├── bus_api.py         实时公交接口封装与到站估算
├── profile.py         出行习惯学习与地点记忆（方向推断的数据底座）
├── map_render.py      线路地图渲染（瓦片拼接 + 站点/车辆标注）

├── holiday_api.py     在线节假日 / 补班日

```
